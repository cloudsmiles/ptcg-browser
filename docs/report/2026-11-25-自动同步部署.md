## 发布时发现并处理的问题

1. 上游 JSON 大于 CDN 的 20 MB 限制，且服务器访问 GitHub Raw 超时。数据下载改用可访问的 GitHub API 原始内容响应，仍固定完整提交版本；图片保持按需从 CDN 下载。
2. 首次访问时慢缩略图会占用 HTTP 连接，低优先级索引可能长期排队。保留首屏绘制后的延迟，将索引请求改为高优先级。新增真实 HTTP 慢图片夹具：每张图片延迟 2 秒时，原逻辑在 8 秒内无法启用搜索，修复后通过同一断言。
3. 窗口尺寸回归脚本原先可能在新布局完成前按旧页面高度滚动，造成假失败。脚本增加布局帧等待，再按新的页面高度验证尾部卡牌。
